# ML_Boosting_Assignment
Assignment to use Machine Learning to best predict bike rentals for a fictional company 

For my portion of the group assignment I needed to model, tune (hyper parameter) and evaluate the Machine Learning (Boosting) model I created. 
These results were then compare to other Machine Learning Strategies such as Random Forest and Bagging. 

In the end Boosting was the most effective strategy nad yeilded the lowest error markers.
